# Лабораторная работа №2 по САПР

Автор: Демьянов Александр, группа М3О-407Б-23

Проект на SystemVerilog: мастер и слейв шины AMBA APB с четырьмя 32-битными регистрами.

## Файлы
- `apb_master.sv` - мастер шины APB (задачи `apb_write` и `apb_read`)
- `apb_slave.sv` - слейв шины APB (регистры по смещениям 0x0, 0x4, 0x8, 0xC)
- `top.sv` - модуль верхнего уровня и тестовая последовательность
